# 인스턴스화를 막으려거든 `private` 생성자를 사용하라

---

## 📌 핵심 요약

- 어떤 클래스는 **인스턴스를 만들 필요가 없을 때**가 있다.  
  예: `Math`, `Collections`, `Arrays` 같은 **유틸리티 클래스**
- 자바는 생성자를 작성하지 않으면 **기본 생성자**를 자동으로 만든다.  
  → 즉, 실수로라도 `new` 키워드로 객체를 만들 수 있음
- **명시적으로 `private` 생성자를 선언**하여 인스턴스 생성을 막자.

---

## 💡 예시 코드

```java
public class UtilityClass {

    // 인스턴스화를 막기 위한 private 생성자
    private UtilityClass() {
        throw new AssertionError(); // 혹시 호출되면 바로 예외 발생
    }

    public static int sum(int a, int b) {
        return a + b;
    }
}
