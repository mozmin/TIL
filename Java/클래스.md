## 🚀 Java의 클래스: 외부 클래스와 내부 클래스 (중첩 클래스)

자바에서 클래스 안에 또 다른 클래스를 정의할 수 있는데, 이를 **중첩 클래스(Nested Class)**라고 부릅니다.

이 개념을 쉽게 비유로 설명해 볼게요.

- **외부 클래스 (Outer Class): 🚗 자동차**
    - 우리가 일반적으로 만드는 클래스입니다. (예: `public class Car { ... }`)
    - 독립적으로 존재할 수 있습니다.
- **내부 클래스 (Inner Class): 🔧 자동차의 엔진**
    - 외부 클래스(`Car`) 내부에 정의된 클래스입니다.
    - 존재 이유: "자동차(`Car`)와 아주 밀접하게 연관되어 있어서, `Car` 없이는 존재 의미가 없거나, `Car`의 부품처럼 동작하게 하고 싶을 때" 사용합니다.

---

## 💡 내부 클래스(Nested Class)의 4가지 유형

내부 클래스는 크게 4가지로 나뉩니다. 이 중 **1번과 2번의 차이**를 아는 것이 가장 중요합니다.

### 1. (인스턴스) 내부 클래스 (Instance Inner Class)

**"외부 클래스의 인스턴스(객체)에 속한 클래스"**

`static` 키워드가 **없는** 내부 클래스입니다.

**특징:**

- 외부 클래스(`Car`)의 객체가 **먼저 생성되어야만** 내부 클래스(`Engine`) 객체를 생성할 수 있습니다.
- **외부 클래스의 모든 멤버(`private` 포함)에 자유롭게 접근**할 수 있습니다. (마치 '내 몸의 일부'처럼)

**예시 코드:**

```java
class Car { // 외부 클래스
private int fuel; // 외부 클래스의 인스턴스 변수

    public Car(int fuel) {
        this.fuel = fuel;
    }

    // 1. 인스턴스 내부 클래스
    class Engine {
        public void start() {
            // 외부 클래스의 private 멤버에도 접근 가능
            if (fuel > 0) {
                System.out.println("엔진이 작동합니다. (남은 연료: " + fuel + ")");
            } else {
                System.out.println("연료가 부족해 시동을 걸 수 없습니다.");
            }
        }
    }

    public Engine getEngine() {
        return new Engine(); // 내부 클래스 생성
    }
}
```

**사용 방법:**
```java
// 1. 외부 클래스 객체를 먼저 생성해야 합니다.
Car myCar = new Car(10);

// 2. 그 객체를 통해서 내부 클래스 객체를 생성합니다.
// (보통 외부 클래스의 메서드를 통해 받아오는 경우가 많습니다.)
Car.Engine myEngine = myCar.getEngine();
// (직접 생성하려면: Car.Engine myEngine = myCar.new Engine();)

myEngine.start(); // 출력: 엔진이 작동합니다. (남은 연료: 10)`
```

### 2. 정적 내부 클래스 (Static Inner Class)

**"외부 클래스 자체에 속한 클래스"** (가장 많이 사용됨)

`static` 키워드가 **있는** 내부 클래스입니다.

**특징:**

- 외부 클래스의 객체(인스턴스)가 **없어도** 생성할 수 있습니다.
- 외부 클래스와 "관련은 있지만, 독립적으로 존재할 수 있는" 클래스를 만들 때 씁니다.
- **외부 클래스의 `static` 멤버에만 접근**할 수 있습니다. (인스턴스 멤버(non-static)에는 접근 불가!)

**예시 코드:**

```java
class Car { // 외부 클래스
private int fuel; // 인스턴스 변수
private static int carCount = 0; // 정적(static) 변수

    // 2. 정적 내부 클래스
    static class CarManual {
        public void printInfo() {
            // 정적 내부 클래스는 외부 클래스의 인스턴스 멤버에 접근 불가
            // System.out.println("현재 연료: " + fuel); // <-- 에러 발생!

            // 외부 클래스의 static 멤버에는 접근 가능
            System.out.println("지금까지 생산된 차량 수: " + carCount);
        }
    }
}
```

**사용 방법:**

```java
// 외부 클래스 객체 생성 없이 바로 생성 가능
Car.CarManual manual = new Car.CarManual();

manual.printInfo(); // 출력: 지금까지 생산된 차량 수: 0`
```
> 💡 [현업 Tip]
static 내부 클래스는 **빌더 패턴(Builder Pattern)**이나, 관련 있는 DTO를 묶어둘 때 정말 많이 사용됩니다.

```java
// DTO 묶어두기 예시
public class ProductController {
```

```java
 // ProductController와 관련된 DTO들을 static inner class로 정의
@Getter
static class CreateRequest {
private String name;
private int price;
}
```

```java
@Getter
static class CreateResponse {
private Long id;
private String name;
}
```

### 3. 지역 내부 클래스 (Local Inner Class)

**"메서드 안에 정의된 클래스"**

- 특정 **메서드 내부**에서만 사용되고 버려지는 1회용 클래스입니다.
- 해당 메서드가 호출될 때만 생성되고, 메서드가 끝나면 사라집니다.
- 요즘은 **람다(Lambda)**나 **익명 클래스**로 대체되어 거의 사용하지 않습니다.

**예시 코드:**
```java

class Outer {
void doSomething() {
int localVariable = 10; // 지역 변수

        // 3. 지역 내부 클래스
        class LocalInner {
            void print() {
                // 메서드의 지역 변수에 접근 가능 (final이거나 effectively final)
                System.out.println("로컬 변수 값: " + localVariable);
            }
        }

        // 이 메서드 안에서만 생성하고 사용 가능
        LocalInner inner = new LocalInner();
        inner.print();
    }
}
```

### 4. 익명 내부 클래스 (Anonymous Inner Class)
```java

**"이름이 없는 클래스"**

- 클래스 정의와 객체 생성을 동시에 하는 1회용 클래스입니다.
- 주로 인터페이스나 추상 클래스를 즉석에서 구현할 때 사용합니다.
- 이것 역시 요즘은 **람다(Lambda)**로 대부분 대체됩니다.
```

**예시 코드 (Old Style):**

```java
// 버튼에 클릭 리스너(이벤트 처리기)를 추가하는 예전 방식
button.addActionListener(new ActionListener() {
    // 4. 익명 내부 클래스 (이름이 없음)
    @Override
    public void actionPerformed(ActionEvent e) {
        System.out.println("버튼이 클릭되었습니다!");
    }
});
```
**람다로 대체 (New Style):**
```java
button.addActionListener(e -> System.out.println("버튼이 클릭되었습니다!"));
```

## 📋 요약 정리
| **구분** | **(인스턴스) 내부 클래스** | **정적 내부 클래스** | **지역 내부 클래스** | **익명 내부 클래스** |
| --- | --- | --- | --- | --- |
| **키워드** | `class Inner` | `static class Inner` | `method() { class Inner }` | `new Interface() { ... }` |
| **생성 시점** | 외부 객체 생성 **후** | 외부 객체와 **무관** | 메서드 호출 시 | 객체 생성 시 (1회용) |
| **외부 접근** | **모든 멤버** 접근 가능 | **`static` 멤버만** 접근 가능 | `static` + `final` 지역 변수 | `static` + `final` 지역 변수 |
| **주요 용도** | 외부 객체와 생명주기를 같이하는 부품 (예: `Car`의 `Engine`) | **관련 클래스 묶기, 빌더 패턴, DTO** | (거의 안 씀) | (람다로 대체됨) |
| **생성법** | `outer.new Inner()` | `new Outer.Inner()` | (메서드 내부에서만) | (정의와 동시에 생성) |

결론:

현대 Java/Spring 개발에서는 **"정적 내부 클래스(Static Inner Class)"**를 가장 유용하게 사용하며, 람다식이 등장하기 전에는 "익명 내부 클래스"도 많이 사용했습니다.
